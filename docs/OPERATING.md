# תפעול שוטף: מה רץ לבד ומה באחריותך

## מה רץ לבד (בלי לעשות כלום)

פעמיים ביום, ב-08:15 וב-17:15, Task Scheduler מריץ את `jobradar run`. ההרצה לא תלויה ב-Claude Desktop, והיא רצה גם אם אף אפליקציה לא פתוחה. אם המחשב היה כבוי או ישן בשעה הזאת, ההרצה מתבצעת כשהוא נדלק.

כל הרצה עושה את הצעדים האלה:
1. **אוספת משרות:** מאתרי החברות, מהפיד הישראלי (techmap) וממיילי ההתראות של לינקדין.
2. **מסננת בקוד:** בכירות, תחום, מיקום, שנות ניסיון, ומשרות בנות יותר מ-48 שעות.
3. **משלימה תיאור:** למשרות מ-Comeet, Lever ו-Greenhouse שהגיעו בלי תיאור.
4. **סינון מהיר (Haiku)** לפי הפרופיל שלך.
5. **הערכה מעמיקה (Sonnet)** לכל מה שעבר, לפי השיטה ב-`prompts/deep_eval.md`.
6. **פינגים לטלפון** ודוח יומי ב-`reports/<תאריך>.md`.

## מה מגיע לטלפון

| פינג | מה זה | מה עושים |
|---|---|---|
| 🎯 / ⭐ משרה עם ציונים | התאמה חזקה (⭐ = חברה מועדפת) | פותחים את הקישור. אם זה מעניין, מבקשים ממני `/cv <מספר>` |
| ✏️ באותו פינג | קו״ח מותאם יסגור את הפער | `/cv <מספר>` |
| 🤝 באותו פינג | הקו״ח לא יעבור סינון קר (שנים, תואר, כלי חובה) | מחפשים הפניה: "מי אני מכיר ב-<חברה>?" |
| 👀 משרות בלי תיאור | עברו סינון ראשוני, אבל אין להן טקסט (בעיקר מלינקדין) | אם משהו מעניין, מעתיקים את התיאור מלינקדין ומבקשים ממני להעריך (`jobradar paste <id>`) |

אם אין פינג, לא נמצא משהו שעובר את הסף. הכל עדיין מופיע בדוח היומי.

## חלון המעקב (כל יום ב-12:00)

- **מה מגיע:** פוש לטלפון עם סיכום ("N לעיון · M להגשה" ומשפך של יומיים, שבוע וחודש), וחלון JobRadar שנפתח במחשב.
- **מה בחלון:** לוח של השבוע האחרון.
- **מה עושים:** עוברים על הממתינות עם Enter, ומסמנים כל משרה: **להגשה (A)**, **הגשתי (S)** או **לא מתאים (D)** עם סיבה קצרה.
- **קו״ח:** למשרה שרוצים להגיש אליה יש בפאנל כפתור **"צור קו״ח למשרה הזו"**, שמכין PDF מותאם בתוך החלון (2–5 דקות, מהמכסה).
- **בכל רגע אחר:** קיצור הדרך JobRadar בשולחן העבודה.
- **פירוט:** `docs/TRACKER.md`.

## הדוח היומי

`reports/<תאריך>.md` מקבל מקטע חדש בכל הרצה. כל מקטע מכיל ארבע טבלאות, שורה אחת לכל משרה:
1. **לסקירה:** עברו את ההערכה המעמיקה (strong / good / stretch).
2. **נפסלו בהערכה המעמיקה:** עם הסיבה העיקרית.
3. **עברו את Haiku בלי תיאור.**
4. **נפלו ב-Haiku.**

הפירוט המלא של משרה (דרישות, חישוב הציון, מתכון קו״ח): `jobradar show <מספר>`, או פשוט לשאול אותי "למה #123 קיבלה 5?".

## מה באחריותך, ומתי

| מתי | מה | איך |
|---|---|---|
| **כשמגיע פינג** | להחליט: להגיש, לבקש הפניה או לוותר | `/cv <מספר>` לקו״ח מותאם |
| **כל יום ב-12:00** (כ-5 דקות) | לעבור על הממתינות בחלון המעקב ולסמן כל אחת | Enter, ואז A / S / D |
| **כשהגשת או דיברת עם מישהו** | לרשום, כדי שהמערכת תציג תהליכים פתוחים ותזכורות | משפט רגיל, או `/log` |
| **פעם בשבוע** (כ-15 דקות) | לדרג את המשרות שקיבלת עליהן פינג (good / ok / bad + משפט "למה") | `/weekly` |
| **כשמשהו בקו״ח או בניסיון משתנה** | פרויקט חדש, קורס, מספר שנזכרת בו, תואר שהוענק | לספר לי. אני מוסיף שורה אמיתית לקו״ח האב (`profile/cv.md`) אחרי שתאשר |
| **כשההעדפות משתנות** | תחומים, מיקום, סוג תפקיד, מה פוסל | לספר לי. אני מעדכן את `profile/profile.md` ואת הסינון |
| **כשרוצים חברה חדשה** | להוסיף למעקב או למועדפות | שם החברה או קישור לדף המשרות |
| **פעם בחודש** | לייצא מחדש את אנשי הקשר מלינקדין | `docs/NETWORKING.md` |

**למה הדירוג השבועי חשוב:** כל משפט "למה" שלך הופך לדוגמה בכל הערכה עתידית. מ-30 דירוגים ומעלה אפשר למדוד את איכות ההתאמה (`jobradar eval`) ולכוון את הספים.

## מכסה

הסינון המהיר והערכה המעמיקה משתמשים במנוי ה-Pro שלך, אותן מגבלות כמו בצ'אט. בממוצע זה כמה קריאות Haiku וכמה קריאות Sonnet ביום, וכל הערכה מעמיקה לוקחת בערך 3 דקות. אם המכסה נגמרת באמצע, מה שלא טופל ממתין להרצה הבאה, ושום דבר לא אובד.

## כשמשהו לא עובד

- **לא מגיעים פינגים בכלל:** `jobradar doctor --ping`. אם פינג הבדיקה לא מגיע, בודקים באפליקציית ntfy את שם הנושא ואת השרת (ntfy.sh).
- **לא מגיעות משרות מלינקדין:** בלינקדין → Jobs → Job alerts, לוודא שכל התראה מוגדרת ל-Daily ול-Email. ב-Gmail, לוודא שהמיילים מקבלים את התווית `jobradar`.
- **מקור נכשל:** לשאול אותי "מה המצב של ההרצות?". אני בודק את `data/logs/jobradar.log`.
- **משרה טובה לא הגיעה:** לשאול "למה לא קיבלתי את X?". אני בודק באיזה שלב היא נפלה ולמה.
