# מעקב משרות (Tracker)

הרדאר מוצא משרות. המעקב מתחיל איפה שהרדאר נגמר: מה עשית עם כל משרה שהוצגה לך, ומה עוד מחכה לך.

## 2. הסטטוסים

| סטטוס | משמעות | צבע |
|---|---|---|
| **בהמתנה לעיון** | הרדאר הציג לך את המשרה ועוד לא הסתכלת | כתום |
| **בהמתנה להגשה** | הסתכלת ולא דחית | כחול |
| **הוגש** | שלחת מועמדות | ירוק ✓ |
| **נדחה לאחר עיון** | הסתכלת והחלטת שלא | אפור |

**מה נחשב "הגיעו":** כל משרה שהרדאר הציג לך. כלומר כל משרה שעברה את הסינון המהיר בלי תיאור, וכל משרה שעברה הערכה מעמיקה עם פסק דין שאינו "no". משרות שנפסלו בקוד או ב-Haiku לא נספרות, כי לא הוצגו לך.

**המשפך** נספר לפי יום ההופעה. "שבוע" פירושו המשרות שהופיעו בשבעת הימים האחרונים, ומה עשית עם כל אחת מהן עד עכשיו.
- **עיינתי:** כל מה שכבר לא בהמתנה לעיון.
- **הגשתי:** אחוז ההגשה מתוך מה שעיינת בו.

**דירוגים שכבר נתת:** משרה שדירגת good בכיול נכנסת ישר כ"בהמתנה להגשה". משרה שדירגת bad נכנסת כ"נדחה".

## 3. שימוש יומיומי

- **כל יום ב-12:00:**
  - פוש לטלפון עם הסיכום, למשל: "📋 5 לעיון · 2 להגשה · שבוע: 12 הגיעו · 9 נבדקו (75%) · 3 הוגשו (33% מהנבדקות)".
  - חלון המעקב נפתח במחשב. אם המחשב היה כבוי או ישן, הוא נפתח כשהמחשב חוזר.
- **בכל רגע אחר:** קיצור הדרך **JobRadar** בשולחן העבודה, או `jobradar inbox`.
- **בחלון:**
  - **Enter:** הממתינה הבאה, מהחדשה לישנה.
  - **O:** פתח את המשרה.
  - **A:** להגשה.
  - **S:** הגשתי.
  - **D:** לא מתאים. נפתחות סיבות מהירות, או משפט חופשי ואז Enter.
  - **U:** החזר לעיון.
  - **↑ / ↓:** מעבר בין משרות.
  - **Esc:** סגור.
  - אחרי כל החלטה עוברים לממתינה הבאה, ויש "ביטול" ל-5 שניות.
- **קישורים:** כל קישור למשרה נפתח ב-Chrome.
- **קו״ח מותאם (📄 בפאנל המשרה):**
  - הכפתור **"צור קו״ח למשרה הזו"** מריץ את אותה שיטה כמו `/cv`.
  - **תיאור המשרה** נשאב לבד, לפי הסדר: מה-DB, ממערכת הגיוס (Comeet / Lever / Greenhouse), מדף המשרה, או בחיפוש של אותה משרה באתר החברה. לינקדין לא נפתח לעולם. אם לא נמצא תיאור, החלון מבקש להדביק אותו.
  - **כמה זה עולה:** קריאת מודל אחת מהמכסה, ועוד קריאת חיפוש כשאין תיאור. לוקח 2–5 דקות. אפשר לסגור את החלון בינתיים, והשרת נשאר פעיל עד שהקו״ח מוכן.
  - **מה מוצג כשהוא מוכן:** תצוגה מקדימה (לחיצה מגדילה), כפתורי PDF / הערות / תיקייה, הכותרת, הסיכון העיקרי והשאלות הפתוחות.
  - **שאלות פתוחות:** מאחר שאין שיחה, כל שאלה ש-`/cv` היה שואל נענית בברירת המחדל הבטוחה. כדי לענות ולשפר: `/cv <מספר>` בצ'אט עם Claude.
  - **איפה הקבצים:** ה-PDF לשליחה נשמר ב-`profile/tailored/CV <שם> - <תפקיד> - <חברה>.pdf`. קבצי העבודה (`.md`, הערות, תיאור המשרה) נשמרים בנפרד, ב-`profile/tailored/work/`.
  - **בכרטיס:** 📄 = יש קו״ח, ⏳ = בהכנה.
- **משרה בלי תיאור** (לינקדין או techmap): העתק את התיאור לקובץ והרץ `jobradar paste <id> --file desc.txt`. כך היא מקבלת הערכה מלאה. גם יצירת קו״ח שומרת את התיאור שנמצא ב-DB.
- **בצ'אט עם Claude:** אפשר לכתוב "הגשתי למשרה של Moon Active", והוא יריץ `jobradar track <id> applied`.

## 4. פקודות

```bash
jobradar inbox                 # פותח את החלון
jobradar inbox --push          # פוש לטלפון ואז חלון (זה מה שרץ ב-12:00)
jobradar tracker               # סיכום בטרמינל + משרות השבוע
jobradar tracker --state to_apply
jobradar track 5972 applied    # עדכון סטטוס (to_review / to_apply / applied / dismissed)
jobradar track 5727 dismissed --note "בכיר מדי"
jobradar schedule windows --inbox --time 12:00   # יוצר את קובץ התזמון וקיצור הדרך
jobradar cv 5972               # קו״ח מותאם, כמו הכפתור בחלון (מהמכסה)
jobradar cv 5972 --posting-file desc.txt   # עם תיאור שהעתקת בעצמך
jobradar cv-pdf 5972           # הדפסה מחדש של ה-PDF אחרי עריכת ה-.md (בלי מודל)
```

## 5. פרטיות ובטיחות

- **מקומי בלבד:** החלון רץ על המחשב שלך, בכתובת `127.0.0.1`, ואי אפשר לגשת אליו מבחוץ. כל שינוי נכתב ישר ל-`data/jobradar.db`.
- **בלי שיתוף:** החלון מציג שמות של אנשי הקשר שלך, ולכן לא משתפים אותו ולא מעלים אותו לשום מקום.
- **סגירה עצמית:** השרת המקומי נסגר לבד כחמש דקות אחרי שסוגרים את החלון.
