# נטוורקינג ותהליכי הגשה

## הרעיון

הנטוורקינג נשמר באותו מסד נתונים של המשרות, ולכן כל חלק במערכת יודע עליו:
- **בפינג על משרה:** ⭐ אם החברה מועדפת, 🤝 מי אתה מכיר שם, 📌 אם כבר יש לך תהליך בחברה.
- **בדוח היומי:** לכל התאמה יש רשימת אנשי קשר בחברה והצעה למי לפנות להפניה.
- **ב‑`/weekly`:** תזכורות שהגיע זמנן ותהליכים שמחכים לצעד הבא.
- **בעמוד המקומי** (`jobradar view` → `reports/network.html`): תזכורות, תהליכים לפי שלב, חברות עם התאמות שבהן אתה מכיר מישהו, שיחות אחרונות ואנשי קשר משמעותיים.

## שלושה סוגי רשומות

| רשומה | מה היא | דוגמה |
|---|---|---|
| **איש קשר** (contact) | אדם: חברה, תפקיד, סוג קשר, חוזק הקשר (1–3), איך הכרתם, הערות | דנה לוי, Data Lead ב‑Wix, חברה מהצבא, חוזק 3 |
| **שיחה** (interaction) | שיחה, הודעה, פגישה או אירוע, עם תאריך ותזכורת המשך אופציונלית | "קפה עם דנה, תעביר קו״ח לצוות הדאטה" · ⏰ בעוד שבוע |
| **תהליך** (application) | הגשה למשרה: סטטוס, מי הפנה, הצעד הבא ותאריך שלו, היסטוריה | Data Engineer ב‑Wix · interview · via דנה |

**חוזק קשר:** ‏1 = קשר רופף (ככה מסומנים כל מי שיובאו מלינקדין), ‏2 = מכירים, ‏3 = קרוב, סביר שיפנה אותך.
**סטטוסים של תהליך:** ‏interested → applied → screening → interview → offer, או rejected / withdrawn / ghosted.

## איך מכניסים מידע

### 1. ייבוא מלינקדין (פעם בחודש בערך) 🧑
1. בלינקדין: **Me → Settings & Privacy → Data privacy → Get a copy of your data**.
2. מסמנים **Connections** בלבד ולוחצים Request archive. הקובץ מגיע במייל, בדרך כלל תוך כמה דקות.
3. מחלצים את `Connections.csv` ומריצים:
   ```
   jobradar net import-linkedin Connections.csv
   ```
4. ייבוא חוזר מעדכן חברה ותפקיד בלבד. מה שכתבת ידנית (חוזק, הערות, סוג קשר) לא נדרס.

אחרי הייבוא כדאי לעבור עם הסוכן על הרשימה ולסמן את מי שאתה באמת מכיר. לינקדין לא יודע מי חבר ומי סתם קליק.

### 2. בשיחה עם הסוכן (הדרך היומיומית)
כותבים לו במשפט רגיל, למשל:

> "דיברתי היום בוואטסאפ עם דנה לוי מ‑Wix. יש להם פתיחה בצוות דאטה, היא תעביר את הקו״ח שלי. להזכיר לי לבדוק איתה ביום ראשון."

הסוכן מתרגם את זה לפקודות ומראה לך מה נרשם:
```
jobradar net add --name "Dana Levi" --company Wix --relationship friend --strength 3      # אם היא לא קיימת
jobradar net log "Dana Levi" --summary "יש פתיחה בצוות דאטה, תעביר קו״ח" --channel whatsapp --follow-up 2026-10-04
jobradar apps add --company Wix --title "Data Engineer" --status interested --via "Dana Levi"
```
אפשר גם לכתוב `/log` ואחריו המשפט.

### 3. ישירות בטרמינל
כל פקודה למטה עובדת גם בלי הסוכן.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `net import-linkedin <csv>` | ייבוא קשרים מלינקדין |
| `net add --name ... [--company --role --relationship --strength --how-met --notes --tags]` | הוספת איש קשר, או עדכון אם כבר קיים |
| `net update <id\|שם> [--strength 3 --append-note "..."]` | עדכון איש קשר |
| `net find <טקסט>` | חיפוש לפי שם, חברה, תפקיד, תגיות או הערות |
| `net at <חברה>` | את מי אני מכיר בחברה |
| `net show <id\|שם>` | איש קשר עם היסטוריית שיחות |
| `net log <id\|שם> --summary "..." [--channel --date --follow-up +7 --app <id>]` | רישום שיחה |
| `net followups [--days 7]` · `net done <id>` | תזכורות שהגיע זמנן, וסימון תזכורת כבוצעה |
| `apps add --job <id> \| --company --title [--status --via --note]` | פתיחת תהליך |
| `apps update <id> [--status --note --next "..." --next-on +3 --via]` | עדכון תהליך |
| `apps list [--all]` · `apps show <id>` | רשימת תהליכים, ותהליך עם ההיסטוריה שלו |
| `view` | עמוד מקומי `reports/network.html` |

כל פקודת רשימה מקבלת `--json`. כך הסוכן קורא את התוצאות בצורה מדויקת.

## פרטיות

- הכל נשמר רק אצלך, בקובץ `data/jobradar.db`.
- ההערכות של המודל לא רואות אנשי קשר. הן רצות מבודדות ומקבלות רק את הפרופיל, הקו״ח והמשרה.
- `reports/network.html` מכיל מידע על אנשים אחרים. הוא נועד לשימוש מקומי בלבד: לא מפרסמים ולא מעלים אותו.
- מספרי טלפון של אנשים אחרים לא נשמרים. מספיקים שם, קישור לינקדין ומייל.

## מה עוד אפשר להוסיף בהמשך (ROADMAP)

- **ייבוא מ‑Gmail:** זיהוי אוטומטי של מיילים ממגייסים ושל אישורי הגשה ("Thank you for applying"), ועדכון סטטוס.
- **הצעות פנייה יזומות:** הצלבה של התאמות טובות עם קשרים מדרגה 2.
- **תזכורת לקשרים שהתקררו:** "לא דיברת עם X כבר 3 חודשים".
